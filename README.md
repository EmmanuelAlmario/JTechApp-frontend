# JTech Frontend

> Frontend de JTech Ecommerce, desarrollado en React + Vite + Tailwind CSS + reactBits.

Este repositorio fue separado del repositorio principal [JTechApp](https://github.com/EmmanuelAlmario/JTechApp) para facilitar el despliegue independiente del frontend y backend.

---

## Stack

- React 18
- Vite
- Tailwind CSS
- Axios
- React Router
- Framer Motion
- React Bits (animaciones)
- Sonner (notificaciones)

---

## Requisitos

- Node.js 20+
- Backend corriendo en `https://jtechapp.onrender.com`

---

## Instalación

```bash
npm install
npm run dev
```

---

## Nota

Este proyecto está en desarrollo activo. Algunas funcionalidades pueden estar incompletas o en proceso de mejora por el hecho de el tiempo que fue dado para realizarlo.
